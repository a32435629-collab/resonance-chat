
Возможности
UI / Панель
Радужная анимированная обводка — переливается через UIStroke + HSV

Радужный градиент фона — плавный переход цветов через UIGradient

Полупрозрачный фон — 35% прозрачности, видно игру через панель

Скруглённые углы — 14px радиус

Перетаскиваемая панель — можно тащить за заголовок куда угодно

Анимированное открытие / закрытие — плавный tween размеров за 0.25 сек

Hover-эффекты — кнопки меняют цвет при наведении

Сообщения
Уникальные цвета ников — по хешу имени получается свой HSV цвет

Время сообщения — HH:MM:SS рядом с ником

Автоскролл — новое сообщение автоматически поднимает скролл вниз

Лимит на экране — 30 сообщений, старые удаляются

История сервера — последние 50 сообщений приходят новому игроку

Word wrap — длинные сообщения переносятся на новую строку

Функции
Антиспам — cooldown 0.5 сек между сообщениями

Лимит длины — 200 символов на сообщение

Санитайзер — удаляет управляющие символы

Фильтр мата — опционально (список в src/server/filters/badwords.lua)

Фильтр ссылок — опционально (FILTER_LINKS = true в конфиге)

Системные уведомления — вход / выход игроков

Личные сообщения — /w <ник> <текст>

Действия от третьего лица — /me <действие>

Архитектура
Сервер — 17 модулей, разделены по логике

Клиент — 9 модулей, каждый отвечает за свою часть UI

Сборка — scripts/build.lua склеивает всё в 2 файла в dist/

CI — GitHub Actions автоматически пересобирает dist при push
